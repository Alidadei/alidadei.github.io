# 网站审美规范(供 Agent 开发新网站使用)

> 来源:对 alidadei.github.io(个人站)与 cyberSleepCommunity(社区站)代码与定稿页面的蒸馏。文中数值均为站内实际生效的定稿值,可直接照抄,不要自行"优化"。
> 配套文档:`docs/UI借鉴.md`(审美来源站点)、`docs/个人技术博客写作风格.md`(文字风格);社区站另见其仓库内 `docs/AGENT_HANDOFF.md`、`docs/DATA_CONTRACT.md`。
> 结构:第 0–1 节是两类站共用的灵魂;第 2–8 节以个人站为基准给出具体参数(白昼寄存器);第 9–11 节为共用的文案语气、功能标配与工程红线;第 12 节是社区网站篇——把同一套内核翻译到夜航寄存器,与其冲突处以第 12 节为准;第 13 节为参照实现索引。

## 0. 一句话气质

**同一个灵魂,两个时辰。**

- **个人网站**:**温暖米色纸张上的手写笔记,挂在一扇会随时间呼吸的窗前。**——安静的、手作感的、有生命力的个人站;不是 SaaS 落地页,不是暗色极客终端风,不是资讯门户。
- **社区网站**:**深夜里亮着暖灯的一间小屋。**——深蓝夜空底、暖金月光点缀、说人话的温柔文案;是无广告无追踪的"真实分享者社区",不是 UGC 内容农场,不是论坛瀑布流。

内核一致:温暖、手作、克制、有生命力、阅读优先、坚固——社区站只是把白天的米色书桌换成了深夜的星光窗前(见第 12 节)。

## 1. 五条设计哲学(冲突时按此排序取舍)

1. **有生命力**:页面随真实时间变化——太阳弧位置、晨昏天色、每日一句、农历干支都是活的。新站至少要有一处"活"的元素(实时时段 / 每日内容 / 季节),禁止整站是静态死模板。社区站的对应形态见 12.2 第六条(夜要有一处活的)。站主原话:"背景富有生命力,让阅读没那么枯燥。"
2. **温暖手作纸感**:米色底、暖棕强调、虚线分隔、手写体点缀——像手账和笔记,不像仪表盘。
3. **克制**:动效短小轻柔,无弹跳、无视差轰炸、无大图轮播。每处装饰都要能回答"删掉它页面是否更差";答案是否,就删。
4. **阅读优先**:正文行高 1.8+,字号流式伸缩,长文必有目录和阅读进度,移动端体验与桌面同等认真。
5. **坚固**:防溢出、无 JS 降级、加载有时限兜底、reduced-motion、触屏适配。美观不以脆弱为代价。

## 2. 配色

### 2.1 色板令牌(Tailwind 4 `@theme`,原样复制)

```css
@theme {
  --color-primary: #5b4636;          /* 深咖啡:大标题 */
  --color-primary-light: #7a6252;
  --color-primary-dark: #3d2e22;
  --color-accent: #b07d4f;           /* 焦糖棕:唯一强调色 */
  --color-accent-light: #c99a6b;
  --color-bg: #faf6f0;               /* 米白:页面底 */
  --color-bg-secondary: #f3ece2;     /* 浅米:卡片/嵌套区 */
  --color-bg-tertiary: #ebe2d4;      /* 米灰:chip/技能签 */
  --color-text: #3a2e24;             /* 正文深棕 */
  --color-text-secondary: #5e4d3e;
  --color-text-muted: #8c7b6a;       /* 弱化文字/日期 */
  --color-border: #ddd2c2;           /* 米灰描边 */
  --color-success: #6b8e4e;          /* 低饱和橄榄绿 */
  --color-warning: #c49432;
  --color-error: #b84c3a;            /* 砖红,不用正红 */
}
```

### 2.2 用法规则

- 面积比约 **80 / 15 / 5**:米色底 + 棕色字为主,`accent` 只做小面积点缀(链接 hover、活动态、圆点、细线、图标),永远不做大面积铺色。
- accent 透明度阶梯(大量复用,直接取用):
  - `rgba(176,125,79,0.08)` 悬停底色
  - `rgba(176,125,79,0.15)` 悬浮底 / 文字选中
  - `rgba(176,125,79,0.22)` 控件细边框
  - `rgba(176,125,79,0.3)` 链接下划线默认色
  - `rgba(176,125,79,0.42)` 内联代码边框
  - `rgba(176,125,79,0.55)` 虚线分隔线
- **不做暗色模式**。整站恒定暖色;"天黑"只通过天空/背景叙事层表达,不动 UI 令牌。
- 纯白 `#fff` 只允许出现在两类地方:带缩略图的项目卡底色、激活 tab 的文字色。
- 状态色一律低饱和;禁止荧光色、高饱和撞色、大面积纯黑纯白。
- 特殊底色仅两处:内联代码便签黄 `#fff8e7`,代码块浅灰 `#e8e8e8`(浅色,不用深色代码主题)。

## 3. 字体与排版

### 3.1 字体栈(四轨制)

| 用途 | 字体 |
|---|---|
| 正文/UI | `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` |
| Logo/手写点缀 | `Caveat`(仅一处,2rem,色 `#8d6e63`,hover `#a1887f`) |
| 仪式性文字(每日一句、叙事文案) | `serif` + `letter-spacing: 0.08em` |
| 日期/数字/年份/状态 | `font-mono`(ui-monospace 栈) |

中文字体自托管(`@fontsource/noto-sans-sc`);装饰字体至多 1 个、可走 CDN、必须 `display=swap`。

### 3.2 排版数值

- 行高:body **1.8**,正文 .prose **1.9**,标题 **1.3**。
- 字号:中文正文 15–18px 流式(`clamp(15px, calc(13.586px + 0.138vw), 18px)`);页面 H1 用 `text-2xl md:text-3xl`(文章页 `3xl/4xl`);辅助文字 13–15px;chips/标签 12px。
- 标题:字重 700(h4 以下 600),标题不加序号;letter-spacing 标题 `-0.01em ~ -0.02em`,仪式文字 `+0.08em`,超仪式标签行 `+0.35em`(如「· 内 容 整 理 中 ·」)。
- 段落间距 1.1em;紧密相关的内容收窄成组(如引出代码块的段落 `margin-bottom: 0.6em`)。
- 文字层级三阶:`text` → `text-secondary` → `text-muted`,弱化信息一律降阶,不许用浅灰假弱化。
- 链接:正文内链接带下划线,默认色 `rgba(176,125,79,0.3)`,hover 变实色 accent,`text-underline-offset: 3px`,过渡 0.2s。
- 选中文字:`background: rgba(176,125,79,0.2)`。
- 滚动条:6px 细条,thumb 用 `border` 色,hover 加深。

## 4. 布局

- 常规页:`max-w-6xl`(1152px)居中,`px-4 sm:px-6 lg:px-8 py-8`;紧凑列表 `max-w-3xl/4xl`;卡片墙页 `max-w-[1040px]`。
- 断点:sm 640 / md 768 / lg 1024,移动优先。
- 文章页:正文与目录栏宽比约 **4:1**(grid `1121fr : 279fr`),目录 `sticky top-8`,`max-h-[70vh]` 内部滚动。
- 个人页:左栏 240px 个人卡 sticky(`top-24`),右栏内容 `max-w-3xl`;移动端个人卡变为置顶横条。
- 圆角体系:卡片 `xl`(0.75rem);图片/代码块 0.75rem;按钮 `lg`(0.5rem);小按钮/内联元素 0.375rem;chips、进度球全圆 `9999px`。
- 阴影极轻三档:静态 `0 4px 12px rgba(0,0,0,0.06)`;代码块 `0 2px 8px rgba(0,0,0,0.04)`;hover 用 Tailwind `shadow-md` + `-translate-y-0.5`。禁止大阴影、发光边框。
- 间距走 4/8 网格;卡片内边距 p-6,栅格 gap-6。

## 5. 签名元素(站格识别物;新站至少继承前 3 个)

1. **虚线分隔线**:`2px dashed rgba(176,125,79,0.55)`——用于 `hr`、非首个 `h2` 上方、About 区块标题底边。这是全站最具辨识度的元素。
2. **标题渐变短线**:48px × 3px,`linear-gradient(90deg, accent, accent-light)`,圆角 2px,置于文章 H1 下方。
3. **胶囊 chip**:标签 `padding: 2px 10px; font-size: 0.75rem; border-radius: 9999px`,底 `bg-tertiary`,hover 泛 accent。
4. **语义圆点**:实心棕 = 基础/进行中;发光琥珀(`#c99a6b` + 2px 光环)= 热点/在线;虚线空心 = 未来/规划。三态语义全站一致。
5. **状态点光晕**:`1.5px` 圆点 + `box-shadow: 0 0 0 3px rgba(176,125,79,0.12)`。
6. **目录地图钉**:TOC 活动指示为 3px 竖线 + 顶端泪滴形地图钉(clip-path 绘制,accent 渐变)。
7. **手写体 Logo + 个人小图**:站名 Caveat 手写体,旁边一枚 48px 个人符号图。
8. **内联代码便签黄**:见 2.2。

## 6. 组件规范

### Header
- `sticky top-0`,透明底 + `backdrop-blur-sm`,高 h-16,左右 padding 6/8/12 随断点。
- 导航项 `px-3 py-2 rounded-md`;激活项 `text-accent font-bold`,其余 `text-muted` hover 加深;无下划线、无底色块。
- 语言切换是纯文字链接("English / 中文"),放导航右侧,不做按钮不做旗帜。
- 移动端汉堡按钮 → `max-height + opacity` 下拉菜单(300ms),点外部关闭,图标在汉堡/叉之间切换。

### Footer
- `border-t border-border bg-bg-secondary`,内容 `max-w-6xl`:左边 © 行 + 文字链接(友链),右边内联 SVG 图标(GitHub / 邮箱),图标 `text-muted hover:text-primary`。

### 卡片(项目/作品)
- 白底 `rounded-xl border border-border`;hover:`border-accent/50 + shadow-md + -translate-y-0.5`,`transition-all`。
- **整卡可点**(外链 `target="_blank" rel="noopener noreferrer"`);缩略图 `aspect-[2/1] object-cover`,懒加载。
- 卡内结构:mono 12px 状态行(状态点 / 斜杠 / 年份)→ `text-lg font-semibold text-primary` 标题 → `text-sm text-secondary line-clamp-2` 一句话简介。
- 卡片网格:`sm:grid-cols-2 lg:grid-cols-3 gap-6`。

### 列表页(博客/项目通用骨架)
- H1 行内联工具图标(搜索、RSS):20px stroke SVG,`text-muted hover:text-accent`。
- 分类 tabs:胶囊 `px-3 py-1.5 text-xs rounded-full`;激活 `bg-accent text-white`,未激活描边 `border-border text-text-secondary`,hover `border-accent/50 text-accent`。
- 视图切换:胶囊分段控件(底 `bg-bg-secondary p-0.5`),激活态同 accent;选择存 localStorage。
- 时间线:年份居中做组分隔;中竖线 `w-0.5 bg-border`;条目左右交错,节点圆点 hover `bg-accent scale-125`。
- 无限滚动:IntersectionObserver 哨兵 `rootMargin 200px`,每批 6 个,状态文案(「滚动加载更多…」/「没有更多了」),**SSR 先渲染前 6 个防无 JS 白屏**。
- 搜索:点图标展开输入框(`max-width` 过渡 300ms),输入实时过滤,显示「N 条结果」,ESC 收起。

### 文章页
- 结构:面包屑(博客 › 分类)→ H1 → 渐变短线 → 日期 + tag chips → 正文 + 右栏 TOC。
- TOC:H3 小标题 uppercase `tracking-wide`;`border-l-2 border-border` 轨道,内有 3px accent 进度线(高度 = 阅读进度)和地图钉活动头;层级缩进 `pl-3/6/9/12`,字号逐级递减,活动行 `text-accent font-semibold`。
- scroll-spy:IntersectionObserver 横带(`rootMargin: -(header+24)px 0px -70% 0px`)+ 位置回退;滚到文末自动激活最后一节。
- 移动端 TOC:右缘悬浮球(32px,内嵌 SVG 阅读进度环)→ 右滑面板(w-72,bg 95% 毛玻璃)+ `bg-black/20` 遮罩。
- 代码块:浅灰底圆角块;复制按钮 28px 方块,desktop hover 浮现,触屏常显 55% 透明;复制成功换 ✓ 且 1.5s 后还原。
- 图片:圆角 0.75rem + 轻阴影,上下 2em。

### 折叠面板(CV / 证明模块)
- 全宽 header 按钮,hover `bg-bg-secondary`;箭头 ▼ `rotate-180` 300ms;内容 `max-height` 过渡 300ms ease-in-out。

### 弹层(灯箱/彩蛋墙)
- ESC 与点击遮罩均可关闭;打开时锁 body 滚动;`requestAnimationFrame` 双帧后触发过渡防闪跳。

### 按钮与反馈
- 主按钮:`bg-primary text-white rounded-lg px-4 py-2 text-sm hover:opacity-90`;次按钮:`border border-border text-text-secondary hover:bg-bg-tertiary`。
- **禁止 `alert()/confirm()`**:反馈一律行内化——状态文字、图标临时替换(✓ 1.5s 后还原)、结果计数。
- 所有交互元素有 hover 态 + `transition 0.2s`;焦点可见(`focus-visible`);aria-label/aria-expanded/aria-current 齐全。

## 7. 动效

| 场景 | 参数 |
|---|---|
| 页面/区块进场 | fade-in 0.5s ease-out,位移 ≤12px |
| 卡片交错进场 | 每项延迟 +0.05s,封顶 0.3s(`.stagger-in`) |
| hover/颜色过渡 | 0.2s |
| 折叠/面板/菜单 | 0.3s ease-in-out |
| 天空/时段颜色 | 2s ease(缓慢得几乎察觉不到) |
| 2D→3D 背景交叉淡化 | 1.5s |
| 打字机 | 100ms/字,结束停 600ms |

- 缓动一律 ease / ease-out;**禁 bounce、spring 过冲、无限循环大动画**(星空闪烁等氛围动画除外,且幅度极低)。
- `prefers-reduced-motion: reduce` 必须 全局归零(动画与过渡都压到 0.01ms)。
- 移动端渲染降载:DPR 上限 1.5(桌面 2),粒子/星数减半。
- 依赖时间的视觉在客户端水合前不渲染(SSR 置 null),防时段闪跳。

## 8. 个性化叙事层(站之灵魂,新站至少选一样做深)

- **加载即叙事**:轻量 2D 层秒开 → 中央进度文案(如「距离 07 星球还有 888 光年」,ease-out 4s 倒数)→ 重资源 `requestIdleCallback` 加载 → 分阶段淡入(3D → 干支 → 最新文章,间隔 0.5–1.2s)。**必须有时限兜底,任何失败都不能卡死在加载态**。
- **每日一句**:按日期确定性选取(`(年*366 + 月*31 + 日) % 列表长度`),serif + 0.08em,淡入 1.5s。
- **时间感知**:太阳沿弧线随本地时间移动,天色晨昏渐变(蓝→暖橙→暮紫→夜空),月亮/星星入夜出现。
- **中文时间感**:年/月/日干支三柱打字机,字符按五行配色(木 `#3d8b5a`、火 `#c0392b`、土 `#9a7b4a`、金 `#b8860b`、水 `#2874a6`);按时段问候(夜深了/早上好/下午好/晚上好)。
- **彩蛋**:成就墙一类的隐藏内容,入口低调,值得"发现"。
- **文案有人味**:见第 9 节。

## 9. 文案与语气(中英双语)

- zh/en 双语对等:路由 `/[lang]/`,`<html lang>` 正确,hreflang 互指,所有 UI 文案两语齐全,不做机翻腔。(社区站为单语简体中文,文案规范见 12.7。)
- 中文语气:短句、进行时、留白。进行中用省略号(「滚动加载更多…」),空态直白温和(「暂无文章」「该分类暂无项目」),仪式文案字距拉开(「· 内 容 整 理 中 ·」)。
- 操作反馈说人话:「已复制」式的图标/打勾即可,不弹窗不感叹号。

## 10. 功能标配清单(个人站版;社区站不适用本清单,功能边界见 12.1)

- [ ] 双语路由 + hreflang + 导航栏文字切换
- [ ] RSS(sitemap、canonical、OG、Twitter Card 齐全);RSS 图标点击=复制订阅地址,非跳转
- [ ] 列表页:分类 tabs + 内联搜索 + 结果计数 + 空态文案
- [ ] 长文:TOC(scroll-spy + 阅读进度)+ 移动端进度环悬浮球
- [ ] 代码一键复制(含 `execCommand` 回退)+ 文本流程图 `white-space: pre` 保护
- [ ] 无限滚动 + SSR 首批兜底
- [ ] Service Worker 版本化缓存;关键状态文件零缓存直通
- [ ] 图片流水线:webp ≤1280px,列表缩略图预生成(sharp),`loading="lazy" decoding="async"`
- [ ] KaTeX(仅长文页加载)、Mermaid/文本图不撑破容器
- [ ] 站点级开关/维护态可选,但状态源必须同源可达(国内直连场景,禁依赖 workers.dev 等被墙域名)

## 11. 工程红线(违反即返工)

1. **移动端永不横向溢出**:flex/grid 子元素 `min-width:0`,文字元素 `overflow-wrap:anywhere`;表格、公式、长代码块各自独立横向滚动;交付前跑移动端溢出回归。
2. `prefers-reduced-motion` 必须实现。
3. 无 JS 时首屏内容可见(SSR 兜底,不能整页依赖 hydration)。
4. 触屏适配:`@media (hover: none)` 下,hover 专属控件改为常显(半透明),防误触不挡内容。
5. 图标一律内联 SVG stroke + `currentColor`;不引图标库 CDN;不用 emoji 充当功能图标(装饰性 emoji 除外,如奖项 🎖)。
6. 关键字体自托管;关键状态/数据走同源;外部 CDN 只放可失败的装饰资源。
7. 交互反馈 ≤1.5s 自动还原;加载序列必须有时限兜底。
8. 键盘可操作:折叠、弹层、菜单均可 Tab + Enter/ESC 完成。
9. 不做暗色模式切换、不做 cookie 横幅、不做全屏弹窗广告位(除非站主明确要求)。

## 12. 社区网站篇(cyberSleep 型:收录 + 评分 + 榜单)

适用形态:**只做三件事——收录(提交与浏览犯困内容)、评分(1–5 助眠效果)、榜单(按分排序 + 按失眠类型过滤)。多一件都算多。** 它不是博客:凡博客惯性功能——文章页、TOC、RSS、代码高亮、双语、评论系统——一律不搬进来。本篇只蒸馏**外观设计哲学**;数据结构与工程规则不在此篇,见该仓库 `docs/AGENT_HANDOFF.md` 与 `docs/DATA_CONTRACT.md`。个人站是白昼寄存器,本篇是**夜航寄存器**——同一套内核,换时辰不换灵魂。

### 12.1 一句话气质

**深夜里亮着暖灯的一间小屋:**逛进来的人都是没睡的,灯光是暖的,说话是轻的,没有店员催你买东西。

### 12.2 外观设计哲学(夜航七条,本篇核心)

1. **深而不黑**:夜是蓝的。底色永远带蓝(`#0d0f1a`),禁纯黑;亮度靠层级表达(页面底 → 卡片亮一级 → 输入框暗一级),不靠阴影堆叠。夜航站没有"白",只有"更亮的蓝"。
2. **一盏暖灯**:全站唯一的暖色是 `--gold`,它就是那盏灯——只照"值得看"的(品牌、标题、星、hover 点亮);`--purple` 是"可以碰"的(按钮、激活态、focus 边)。灯不乱照:金色面积恒小(80/15/5),大面积暖色等于天亮,天亮了这座站就不成立。
3. **灯笼阵列,不是仪表盘**:内容是一张张比夜色微亮的小卡(圆角 14),像夜里一排小灯笼;单栏 860px 居中,手机即默认形态。不做侧边栏工作台、不做数据密集表格、不做瀑布流杂志。
4. **星星即图腾**:社区的视觉图腾是星——评分控件、榜单依据、空态缺省符都由它承担。星级控件是全站唯一带预览的交互(hover 逐颗亮),要做到"想点"。
5. **动效是呼吸,不是表演**:hover 只点亮颜色与描边,无位移跳动、无循环大动画、零闪烁零自动播放。给失眠的人逛的站,一切"兴奋"都是 bug。
6. **夜要有一处活的**:至少一个随真实时间呼吸的元素——按时段变化的问候(「夜深了」)、月相、或透明度 ≤0.06 的极淡星点背景。它们是氛围,不与内容争夺注意力。
7. **字要轻声**:标题金、正文月白、辅助雾蓝;居中的仪式感 header(品牌 + 一句副标题);行高 1.8;圆角比个人站大一号。夜里说话,不喊。

### 12.3 夜航空色板(定稿值,原样复制)

```css
:root{
  --bg:#0d0f1a;      /* 深夜蓝黑:页面底 */
  --card:#151a2c;    /* 夜云蓝:卡片/表单底(比页面底亮一级) */
  --line:#2b3152;    /* 靛蓝:描边 */
  --ink:#dfe3f5;     /* 月光白:正文 */
  --sub:#9aa3c7;     /* 雾蓝:次要文字/日期/提示 */
  --gold:#e7c97f;    /* 暖金:标题/强调/星级(白昼 accent 焦糖棕的夜航位) */
  --purple:#4e57a5;  /* 暮紫:一切"可交互"(按钮/激活态/focus 边) */
  --ok:#7fd6a4;      /* 成功 */
  --bad:#e07a7a;     /* 出错(砖红的夜航位) */
}
/* 输入框内嵌底 #0f1322(比卡片再暗一级);footer 链接 #8fb4ff */
```

用法规则(纪律与白昼寄存器完全同构):

- 80 / 15 / 5:夜蓝底 + 月白字为主,暖金只做小面积点缀(标题、星星、type chip、hover);金紫分工见 12.2 第二条——紫色=可点击,金色=值得看,永不互换。
- 层级两阶半:`ink` → `sub`,弱化信息降阶表达;`sub` 不许用于 12px 以下文字,正文对比度必须 ≥ 4.5:1。
- 深度三级:页面底最暗 → 卡片亮一级 → 输入框暗一级;卡片永远浮在夜色上,不做平面白板。
- **夜航站恒夜色,不做亮色切换**(与 APP 品牌一致;站主要求做浅色时先停下确认)。同白昼站恒米色一个道理:时辰由站点身份定死,不做成开关。
- 禁大面积纯黑(`#000`)与促销色;错误色用 `--bad` 砖红,不用正红。

### 12.4 布局

- 单栏 `max-width: 860px` 居中,`body` 上下 32px、左右 14px;header 居中(品牌 + 一句副标题),卡片纵向流;移动端即默认形态,不另做布局。
- 圆角比个人站**大一号**:卡片/表单 14px,按钮 10px,输入框 8px,分类 chip 16px,type chip 10px——夜的柔和。
- 分区之间用留白(22–36px)与卡片底色区分;若需分隔线,用夜航虚线 `1px dashed rgba(231,201,127,0.25)`(白昼虚线分隔的夜航位)。

### 12.5 组件外观规范

**内容卡**(核心物件):
- 底 `--card`,圆角 14,padding 14–16px,间距 10px。
- 标题 17px semibold `ink`,整行可点(外链新窗 + `noopener`),hover 变 `gold`——与白昼"整卡可点、hover 点亮"同律。
- meta 行 13px `sub`:type chip(12px gold 描边圆角胶囊,如「焦虑型」)+ 平均分「★ 4.5 · N 次评价」/ 暂无评分时显示来源域名。
- 评分入口:右上 ghost 小按钮(描边圆角 12,hover 边框变 gold)。
- 榜单不另立组件:按分排序后的列表就是榜单,不加名次徽章、不设领奖台——「★ 4.5 · N 次评价」本身就是身份。

**打分控件(星星,全站图腾)**:五颗内联 SVG 星,默认空心 stroke gold;hover 逐颗预览填充,点击即提交,成功后行内 ✓ 反馈 1.5s(白昼"图标临时替换"同款)。禁 `prompt()/alert()`——P0 的 prompt 是过渡态,不是目标态。

**分类 chips**:居中横排可换行;激活态 `--purple` 实底白字,未激活 `--card` 底 + `--line` 描边 + `sub` 字(白昼 tabs"激活实底/未激活描边"同律)。

**发布表单**:卡片底圆角 14 padding 18;label 13px `sub` 置于输入框上方;输入框 `#0f1322` 圆角 8,focus 边框变 `purple`,无默认 outline 之外的光晕;主按钮 `--purple` 白字圆角 10,次级动作用透明底描边的 ghost 按钮。
- 智能细节:粘贴 B 站分享文本(【标题】+URL)自动拆出标题与链接,标题留空自动兜底——这是收录体验的一部分。

**空态**:必须给出路——「该类型还没有社区推荐，欢迎发布第一条」,指向发布表单;禁止光秃秃的"暂无数据"。

**Footer**:12px `sub` 居中,链接 `#8fb4ff`;常驻一句身份声明「无广告 · 无追踪 · 无账号」,与文档入口、姊妹应用链接同行。

### 12.6 动效(夜航版)

| 场景 | 参数 |
|---|---|
| hover 点亮 | 0.2–0.3s,只变颜色 / 描边 / 亮度,零位移 |
| 卡片 / 表单进场 | 可省;若做,仅 fade 0.4s,不 stagger、不位移 |
| 状态反馈(✓) | 行内出现,1.5s 后自动还原 |
| 氛围元素(星点 / 月) | 循环可以,但周期 ≥4s、透明度 ≤0.06,几乎不可见才算对 |

- 缓动 ease / ease-out,禁 bounce;`prefers-reduced-motion` 必须全局归零(第 7 节要求在此同样生效)。
- 自检标准:**夜里半睡半醒扫一眼,动效不应当被察觉。**

### 12.7 文案与语气(社区版,单语简体中文)

- 称呼有身份:用户是「未寝人」,匿名昵称模式叫「未寝人####」;不说"用户/访客"。
- 典故要一眼能懂:「怀民亦未寝」(《记承天寺夜游》梗)做副标题——引经据典但零门槛,这是社区站的"手写体 Logo 位"。
- 类型标签带画面:「焦虑型 · 思绪停不下来」「兴奋型 · 大脑过电影」——名词 + 间隔点 + 一句共鸣描述,规律全表统一。
- 反馈带人味:「已发布 ✓ 感谢为同类型的失眠伙伴添砖加瓦」;错误不指责:「链接无效，请检查」。
- 品牌符号放宽:🌙 允许出现在 H1 品牌位(全站仅此一处 emoji;功能图标仍按第 11 节用内联 SVG)。

### 12.8 视觉红线(在第 11 节之上)

1. 纯黑禁用;正文对比度 ≥4.5:1;`sub` 色禁用于 12px 以下文字。
2. 金色永不承载交互态,紫色永不充当装饰——两者语义不互换(12.2 第二条)。
3. 零闪烁、零自动播放、零位移跳动;氛围动画透明度 ≤0.06;`prefers-reduced-motion` 必须。
4. emoji 全站仅品牌位一颗(🌙);功能图标一律内联 SVG(第 11 节第 5 条)。
5. 功能越界即返工:出现收录 / 评分 / 榜单之外的区块(文章、评论、标签云、相关推荐…),先停下对照 12.1。
6. `prompt()/alert()` 禁用(P0 过渡态除外);打分必须走星星控件(12.5)。
7. 拿不准的实现取舍,先读该仓库 `AGENT_HANDOFF.md` §6「已知取舍」,列在里面的朴素实现不许顺手"修复"。
