# 一键内容隐藏功能(对外闭站开关)

更新日期:2026-09-07

## 功能定义

在管理后台「🔒 站点开关」页点击**一键隐藏**,对外访客立即只显示首页的星空 3D 动画和每日一句:

- 导航、关于、博客、项目、友链等入口全部消失(首页 header/main/footer 整体隐藏);
- 其余页面没有入口,直接输入 URL 也会被跳回首页;
- 访客侧**立即生效**,不需要等待 GitHub Actions 重新构建;
- 点击**恢复显示**后一切复原,同样立即生效。

**对内不受影响**:登录过管理后台的浏览器会在 `localStorage` 写入站长标记(`cms_owner_at`),守卫脚本据此豁免——站长仍然可以正常浏览全站、继续写文章和开发功能。退出登录即清除标记,可切回访客视角检查隐藏效果。

## 架构

```
管理后台(React 岛屿)
  │  POST /api/site-mode { hidden: true|false }   (X-Session-Token 鉴权)
  ▼
Cloudflare Worker(worker/src/site-mode.ts)
  │  开关状态存 KV(复用 SESSIONS 命名空间,key = site_mode,无 TTL)
  ▼
GET /api/site-mode → { hidden }                    (公开,带 CORS)
  ▲
  │  每个页面加载时 fetch(BaseLayout 内联守卫脚本)
全站访客浏览器
```

### 各文件职责

| 文件 | 职责 |
| --- | --- |
| `worker/src/site-mode.ts` | 开关读写接口;写需要管理后台会话,读公开 |
| `worker/src/index.ts` | 路由挂载 `/api/site-mode` |
| `src/data/site.ts` | `WORKER_URL` 常量(AdminApp 与守卫脚本共用) |
| `src/layouts/BaseLayout.astro` | 内联守卫脚本 + `html.site-locked` 隐藏 CSS(全站生效) |
| `src/pages/[lang]/index.astro` | `_fade2d` 在锁站时保留每日一句不淡出 |
| `src/components/admin/AdminApp.tsx` | 「站点开关」页;登录成功写 `cms_owner_at`,退出清除 |
| `tests/worker-site-mode.test.mjs` | 接口鉴权/读写/非法请求/CORS 测试(`npm run check:cms`) |
| `tests/site-guard.test.mjs` | 守卫脚本行为回归测试(从 dist 产物提取脚本,桩 DOM 跑 7 个场景;已挂进 `npm run build` 末尾,单独跑用 `npm run check:site-guard`) |

### 守卫脚本行为细节(BaseLayout)

1. 开发模式(`import.meta.env.DEV`)直接跳过,本地开发完全不受影响;
2. `/admin` 路径永远跳过——这是锁站时站长唯一的恢复入口;
3. `sessionStorage.site_lock_cache` 缓存本会话已确认的状态:同会话内再次导航**同步**生效,不闪现内容;
4. 每次页面加载仍会 `fetch` 一次最新状态(`cache: no-store`),状态变化(如站长点了恢复)最多一次导航就生效;
5. 锁站逻辑:非首页 `location.replace('/{lang}/')` 跳回首页;首页加 `html.site-locked` 类隐藏 header/main/footer,并保证每日一句可见(主页脚本已淡出时会按 `/quotes.json` 当日规则重建);
6. Worker 不可达时不做任何事(不误伤正常浏览)。

## 恢复途径(锁站时怎么救回来)

- 任意浏览器访问 `https://alidadei.github.io/zh/admin/`(守卫对 admin 路径无条件放行)→ 登录 → 「站点开关」→ 恢复显示;
- 直接调 `POST /api/site-mode`(带有效会话)等效;
- 极端情况可在 Cloudflare 控制台删掉 KV 里 `SESSIONS` 命名空间的 `site_mode` 键。

## 安全边界(与《网站防复制与安全边界.md》的结论一致)

这是一个**访客视角的软开关**,不是内容保护手段:

- 站点是 GitHub Pages 静态托管,无法在服务端按访客区分处理;守卫脚本随页面公开,禁用 JavaScript、直接抓取 HTML/RSS/图片都能绕过;
- 站长标记(`cms_owner_at`)是本机 localStorage 标记,不是鉴权——写接口仍然要过 Worker 的 GitHub OAuth 会话 + 用户白名单;
- RSS、sitemap 与公开资源在锁站期间仍可被拉取(静态构建无法动态摘除)。

适用场景:临时闭站(求职期、评审期、内容整理期)让普通访客只看到「门面」。真正的内容边界仍然以该文档所述的服务端隔离与权利声明为准。

## 上线与回滚

- Worker 先行部署:`cd worker && npx wrangler deploy`(新增接口对旧版前端无影响);
- 前端随后随正常构建发布(GitHub Actions);
- 回滚:前端回滚即失去守卫脚本;Worker 接口为纯新增,无需回滚。
